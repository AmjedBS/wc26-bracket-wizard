# World Cup 2026 Interactive Bracket Predictor

An interactive, responsive single-page web application designed for football fans to simulate and predict the entire tournament outcome of the FIFA World Cup 2026. 

Users can fully map out their predictions, starting from the newly formatted 12-group stage all the way down to the ultimate World Champion podium.

## 🚀 Features

- **Full 48-Team Format Support:** Built specifically around the real baseline World Cup 2026 configuration featuring 12 groups (A through L).
- **Two-Phase Prediction Wizard:**
  1. **Group Stages:** Select 1st, 2nd, 3rd, and 4th place rankings per group, complete with smart duplication tracking and a customized 3rd-place promotion mechanic.
  2. **Knockout Bracket:** Interactive horizontal bracket layout mapping out matches seamlessly across the Round of 32, Round of 16, Quarter-Finals, Semi-Finals, Third-Place Playoff, and the Final.
- **Dynamic Visuals & UI UX:** Beautifully styled dark mode layout featuring dynamic team flags, color-coded seed placements, sleek slide-in view transitions, and celebration animations upon selecting a tournament champion.
- **Persistent State:** Saves user progress instantly to local browser storage (`localStorage`) so that predictions are never lost on page reloads.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and layouts.
- **CSS3:** Custom properties (CSS variables) for modern dark-theming, responsive flex/grid layouts, and elegant keyframe animations.
- **Vanilla JavaScript:** Event-driven application architecture, complete dynamic UI rendering, status validation rules, and persistent browser storage.
